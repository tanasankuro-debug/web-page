# 1. Design Philosophy

## Design Concept

"Technology meets Nature"

ระบบต้องสื่อถึง:

- ความทันสมัย
- ความน่าเชื่อถือ
- การแก้ปัญหาสิ่งแวดล้อม
- ความง่ายในการใช้งาน

แนวทางการออกแบบ:

ผสมระหว่าง

- Apple Design Language
- Google Material 3
- Linear App Design
- Environmental Technology Interface

# 16. UX Principles

System must:

1. User understands within 5 seconds

2. Every action has clear feedback

3. Reduce technical complexity

4. Show visual results instead of only text

5. Make environmental improvement enjoyable
