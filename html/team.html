ดาวเทียม

วิเคราะห์ Landsat 8–9 ผ่าน Google Earth Engine · NDVI · NDBI · LST ย้อนหลัง 11 ปี (พ.ศ. 2559–2569)

สัมภาษณ์ผู้รู้

สัมภาษณ์เชิงลึก ผู้รู้และหน่วยงานที่เกี่ยวข้อง 10 คน เพื่อยืนยันและตีความข้อมูลดาวเทียม

แบบสอบถาม

แบบสอบถามประชาชน 300 คน ในเขตเทศบาลนครขอนแก่น — รับรู้ปัญหาความร้อนเมืองระดับ "มากที่สุด" ค่าเฉลี่ย 4.43

ระบบ Smart Crowdsourcing

ประชาชนสามารถแจ้งจุดเสี่ยงความร้อนในชุมชนผ่าน LINE Official Account "HeatSafe Khon Kaen" ข้อมูลที่ได้รับเชื่อมต่อกับ Smart Map โดยตรง เพื่อให้ทุกคนมีส่วนร่วมในการติดตามและแก้ไขปัญหาเกาะความร้อนเมือง

แหล่งข้อมูล

แหล่งอ้างอิงข้อมูลและเครื่องมือ

Heat Safe Khon Kaen ดึงข้อมูลทั้งหมดจากแหล่งข้อมูลสาธารณะและ API เปิดที่ไม่ต้องใช้ API key — ข้อมูลอัปเดตทุก 15 นาที

🌤️
Open-Meteo Weather API

พยากรณ์อากาศ อุณหภูมิ ความชื้น รหัสสภาพอากาศ WMO — ครอบคลุมพยากรณ์รายชั่วโมงและ 4 วัน · api.open-meteo.com/v1/forecast

🌫️
Open-Meteo Air Quality API

ค่าฝุ่น PM2.5 แบบเรียลไทม์ · air-quality-api.open-meteo.com/v1/air-quality

🗺️
MapLibre GL JS

ไลบรารีแผนที่โอเพนซอร์ส สำหรับแผนที่เรียลไทม์และเลเยอร์ความร้อน/PM2.5 · maplibre.org

🌐
กรมอุตุนิยมวิทยา (TMD)

ข้อมูลพยากรณ์อากาศและเตือนภัยพายุในประเทศไทย · tmd.go.th

🏭
กรมควบคุมมลพิษ (กรมคพ.)

มาตรฐานคุณภาพอากาศและเกณฑ์ AQI ของประเทศไทย รวมถึงข้อมูล PM2.5 รายสถานี · pcd.go.th

💾
Supabase

ฐานข้อมูลและ Edge Functions สำหรับเก็บประวัติค่าสภาพอากาศและ LINE OA webhook · เชื่อมต่อผ่าน Vercel Environment Variables เท่านั้น

▲
Vercel

ให้บริการ hosting และ Serverless Functions สำหรับเว็บไซต์ Heat Safe Khon Kaen · ไม่มีขั้นตอน build — deploy ตรงจาก HTML/CSS/JS
